## About Me

Desenvolvedor focado em Java com Spring Boot e Dart/Flutter, apaixonado por criar soluções eficientes e bem estruturadas. Gosto de trabalhar com boas práticas, organização de código e arquitetura limpa. Tenho experiência na criação de APIs REST, integração com banco de dados (SQLite e PostgreSQL) e desenvolvimento de aplicativos Flutter com design minimalista e funcional.
